# Revit Tools & BIM Services | חנות התוספים והאוטומציות

🌐 **אתר חי ב-Vercel**: [https://tal-store.vercel.app/](https://tal-store.vercel.app/)

חנות מודרנית ומתקדמת לתוספי Autodesk Revit, אוטומציות pyRevit, תבניות משרדיות תקניות, משפחות פרמטריות ושירותי מידול BIM מקצועיים.

---

## 🚀 תכונות מרכזיות
- **עיצוב הנדסי מודרני (Dark Blueprint Mode)** עם שקופיות Glassmorphism, תאימות למובייל ושילוב הלוגו הטכני.
- **קטלוג מוצרים דינמי**: תוספי C#, סקריפטים ב-Python ל-pyRevit, תבניות רוויט משרדיות לפי תקן BIM ישראלי ומשפחות 2D/3D.
- **מערכת סינון וחיפוש בזמן אמת** לפי קטגוריות, תגיות וגרסאות Revit (2021-2025).
- **מודל תצוגה מפורט** עבור כל מוצר עם מפרט טכני, דרישות מערכת והוראות התקנה.
- **עגלת קניות ומחשבון הצעות מחיר** עם פנייה בלחיצה אחת ב-WhatsApp.
- **פאנל ניהול גרפי (Admin Console)** המוגן בקוד גישה לעריכה, הוספה ומחיקת מוצרים בלייב.
